# 07 · 装配界面、运行台和 Agent 流程图

## 目标与交付结果

读者可在一个页面创建和装配 Agent，切换到 MCP／Skill 管理、规则、记忆、权限和运行台。配置视图画出主 Agent 与子 Agent 的关系；运行视图按轮次显示真实触发的连线，点节点可看该 Agent 的工具、审批、状态与媒体。

## 前置模块

完成 [06 AIGC](06-aigc-and-media.md)：后端有稳定 Agent、会话、事件、媒体和配置接口。流程图只读这些数据，不自行推断 SDK 内部动作。

## 技术栈规划

React hooks 管理页面草稿和订阅生命周期；REST 写配置、SSE 读运行事件；流程归属放在与 DOM 无关的共享纯函数中，便于对历史事件做确定性测试。CSS 文件分别承载主布局、浅色覆盖、MCP 和 Skill 页面；`src/i18n.ts` 只翻译平台文案。

## 相关模块文件架构

| 层 | 文件与技术 | 职责 |
| --- | --- | --- |
| 页面状态 | `src/main.tsx`；React hooks、`fetch`、`EventSource` | 当前 Agent、未保存草稿、会话、轮次、待决交互与媒体 |
| 配置模块 | `src/McpManager.tsx`、`src/SkillManager.tsx` | 与主页面分开的 MCP、Skill 工作流 |
| 归属算法 | `shared/agent-flow.ts` | 从事件、委派 ID 和产物构造节点状态，不依赖 DOM |
| 可视化 | `src/AgentFlow.tsx`、`src/styles.css` | 配置图／运行图、动态连线、节点详情 |
| 语言主题 | `src/i18n.ts`、`src/light.css`、模块 CSS | UI 中英与深浅主题，不改用户内容 |
| 测试 | `scripts/agent-flow-test.ts` | 真实事件、旧事件和状态归属的纯函数回归 |

前端只通过 REST 修改配置，通过 SSE 接收运行事件；不能把会话状态只存在浏览器。UI 可缓存选中项和显示偏好，但刷新后的事实应从后端会话与配置重新读取。

## 需求契约

| ID | 必须成立的行为 | 失败／边界 |
| --- | --- | --- |
| UI-01 | 未保存 Agent 草稿与已保存配置区分 | 带脏草稿不能直接新建会话 |
| UI-02 | 配置图显示当前挂载关系，运行图显示会话快照 | 改现有 Agent 不改旧历史图 |
| UI-03 | 真实委派才激活连线；点击节点展示动作与媒体 | 旧事件证据不足时不强行归属 |
| UI-04 | 运行台支持追问、SSE、审批、选择、中断和媒体 | 刷新后可恢复选中会话与事件 |
| UI-05 | 存档提问创建新会话，提示旧上下文不继承 | API 直接续接存档仍拒绝 |
| UI-06 | 中英／深浅主题可切换并保留 | 人格、规则、记忆和消息不自动翻译 |

## 数据与调用链

`src/main.tsx` 管理导航、Agent 草稿、配置保存、会话选择、SSE 订阅、交互弹窗与媒体显示。`src/McpManager.tsx`、`src/SkillManager.tsx` 是独立配置模块。`src/AgentFlow.tsx` 接收 `shared/agent-flow.ts` 归纳的节点、连线和所选轮次。

配置图使用当前编辑草稿，帮助检查挂载关系；运行图使用会话创建时的配置快照，避免保存新配置后篡改旧记录。`shared/agent-flow.ts` 优先读取事件中的 `agentId`、`targetAgentId`、`toolUseId` 和任务 ID；对旧历史仅根据可确认的委派参数、专属 MCP 和媒体归属作保守还原。子 Agent 未被实际调用时保持“已配置”状态，不能仅因挂载就高亮连线。

运行台显示当前轮次、Agent 回答、待决交互、工具事件、模型回退、Credits 和产物。历史演示存档有明显标识；在该页输入新问题调用创建会话接口，并提示旧 SDK 上下文不会传入。`src/i18n.ts` 提供平台文案中英切换；`src/light.css` 与其他样式文件提供深浅主题。切换语言不翻译用户写入的 Agent 人格、规则、记忆和历史消息。

## 关键文件和接口

`src/main.tsx`、`src/AgentFlow.tsx`、`shared/agent-flow.ts`、`src/i18n.ts`、`src/styles.css`、`src/light.css`、`src/mcp.css`、`src/skill.css`。后端会话详情与 SSE 已在前几章完成；本章只需消费并显示，必要时补充事件归属字段。

## 架构约束

- 事件归属必须可追溯到 SDK 工具 ID、父任务 ID 或明确装配关系；证据不足的旧事件不要强行归给某个子 Agent。
- 配置图与运行图使用不同数据源；未保存草稿不可直接运行。多标签页对全局授权使用逐项更新，避免整表覆盖。
- “允许一次”“本会话同工具／同类”“全局允许”“拒绝”“稍后处理”在界面上有清楚区别；等待用户选择时不能显示成模型完成。
- 中英文和深浅色是 UI 状态，刷新后保留；布局需要兼顾小屏宽度和长事件文本。

## 实现步骤（Spec Coding Tasks）

1. **UI-T1 · 页面骨架**：建立 Agent 列表、装配配置、规则、记忆、全局授权、配置清单与运行台导航；加载 `/api/bootstrap`，区分保存状态和编辑草稿。
2. **UI-T2 · 独立配置页**：挂载 `McpManager` 与 `SkillManager`，保存或装配成功后刷新后台来源；装配按钮只修改当前 Agent 草稿，提示还需保存。
3. **UI-T3 · 运行台接线**：创建会话后订阅 SSE；按会话 ID 和事件 ID 去重，显示文本、工具、诊断、用量、待决交互和媒体；追问时先检查当前轮状态。
4. **UI-T4 · 决策交互**：审批弹窗明确展示工具、目标地址、路径和允许范围；`AskUserQuestion` 用选项、复选和自定义答案；“稍后处理”只关闭弹窗。
5. **UI-T5 · 流程纯函数**：从会话快照与所选轮次建立根节点和子节点；优先用 `agentId/targetAgentId/toolUseId/parentToolUseId/taskId`，旧事件仅保守回退。纯函数测试先通过，再绘制 UI。
6. **UI-T6 · 图形交互**：配置图仅展示挂载；运行图依据委派、等待、完成和失败状态改变连线；点击节点查看自己对应的事件和媒体。
7. **UI-T7 · 显示偏好和存档**：平台文案中英切换、深浅主题持久化；历史演示存档显示只读提示，新问题调用创建会话接口。

## 可直接复制的构建提示词

> 为现有本地 Agent 工程完成 React 界面：左侧区分运行台、Agent 装配、规则、记忆、MCP、Skill 和授权；顶部提供中英与深浅主题切换并持久化选择。Agent 编辑区展示主 Agent 到一层子 Agent 的配置图，点击节点查看模型、工具、Skill 和 MCP。运行台使用 SSE 显示多轮会话、审批／提问、工具、用量、模型诊断及媒体；按轮次构造动态流程图，只有真实委派事件才激活连线，点击节点显示该 Agent 的动作。优先使用事件中的明确归属字段，对旧记录保守还原。配置图读草稿，运行图读会话快照。演示存档清楚标识，新提问创建新会话并说明不继承旧 SDK 上下文。不要翻译用户内容。编写流程归属测试，并在图片、视频两个子 Agent 案例中核对连线和产物归属。

## 验收方法

运行 `npm run test:flow`、类型检查与构建。在一个主 Agent 下挂两个子 Agent，配置图应显示两条待命连线；实际只委派其中一个时，只有其连线激活。切换轮次、刷新页面后归属不变。用图片和视频案例分别检查任务与产物对应节点；检查存档提问创建新会话，深浅主题及语言切换不影响 Agent 自定义文本。

## 实现后的校验逻辑

| 对应需求 | 操作 | 通过条件 |
| --- | --- | --- |
| UI-01 | 修改 Agent 但不保存，尝试开始任务 | 阻止运行，保存后才可创建会话 |
| UI-02 | 创建会话后改挂载和模型，再打开旧轮次 | 配置图显示新草稿，旧运行图保留原快照 |
| UI-03 | 挂两个子 Agent，只调用一个；另测失败产物 | 只亮实际委派连线，失败媒体归到证据明确的节点 |
| UI-04 | 运行中刷新、重连、审批、追问和中断 | 无重复事件、错轮事件或失效按钮；页面重新取后端状态 |
| UI-05 | 在存档页输入任务 | 创建新 ID，旧消息不进入新会话；提示文案可见 |
| UI-06 | 切换语言与主题并刷新 | UI 设置保留，原始 Agent 内容逐字不变 |

流程测试验证算法；还需浏览器人工检查连线、弹窗位置、浅色对比度和窄屏长文本。
